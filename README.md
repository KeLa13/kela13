# Xyeta Binder — downloads

[Download the latest Stable installer](https://github.com/KeLa13/kela13/releases/latest/download/XyetaBinder.exe)

[Stable and Beta releases](https://github.com/KeLa13/kela13/releases)

This repository distributes tested installers and component packages. Every file is checked against its release size and SHA-256 before publication. The application reads separate Stable and Beta manifests directly from GitHub.

Application source is maintained in the private project repository. Distribution uses this repository's own GitHub Actions token; no GitHub token is included in the application.
